Kim geldi, kim kaldı

GoatCounter verisi, canlı. Gerçek ziyaret: sayfanın en az 8 saniye açık kaldığı ziyaretler; link önizleme botları buraya girmez.

GoatCounter anahtarı

  1. mserkantan.goatcounter.com → Settings → API → New API key
  2. İzin olarak sadece Read statistics seç, kaydet.
  3. Oluşan anahtarı aşağıya yapıştır.

Anahtar sadece bu tarayıcıda saklanır ve yalnızca GoatCounter’a gönderilir; siteye veya repoya yazılmaz.

# serkantan.org

**Bir ay, bir şarkı.** Her ay tek bir şarkıyı, ona eşlik eden birkaç dize ve kısa notlarla paylaşan kişisel site.

- Yayın: GitHub Pages → https://www.serkantan.org
- Her ayın kalıcı adresi var (`/2026/10/` gibi); ana sayfa her zaman en yeni ayı gösterir.
- Yorumlar Supabase’te, ziyaretçi istatistikleri GoatCounter’da (çerezsiz).

```
index.html            en yeni ayı gösteren ana sayfa
2026/10/index.html    Ekim 2026
assets/css/           ortak stiller
assets/js/            oynatıcı, yorumlar, arşiv rafı, istatistik
data/months.json      arşiv listesi
supabase/             veritabanı kurulum SQL’leri
```

Yeni ay ekleme adımları ve proje notları: `CLAUDE.md`.
